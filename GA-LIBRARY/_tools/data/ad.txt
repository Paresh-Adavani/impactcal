                            Guidelines For Selecting A Shock absorbers

                            In order to select the Industrial Shock absorber suitable for your application collect
                            the data as per the case of impact as shown below. calculate the Energy to be
                            absorbed using the given set of formulate and select the shock absorber whose
                            utilization is the maximum. Also share the calculations with the authorised
                            representative for a confirmation.

  Case 1 - Free Faling Mass

  Input Data                     Formulae
  m = 20Kgs                      Ek=m x g x H = 20 x 9.8 x 0.3               =58.8
  H = 0.3M                       Ep=m x g x s      = 20 x 9.8 x 0.025        =4.9
  S = 0.025 (Expected Stroke)    Et =Ek + Ep       = 58.8+4.9                =63.7
  X = 300 Stroke per hour        Et/Hr = Et x X = 63.7 x 300                 =19110
                                 Me= 2 x Et / (2 x g x H)^0.5
                                 = 2 x 63.7 / (2 x 9.8 x 0.3)
                                 = 21
                                 So we search a shock absorber whose energy capacity is greater
                                 than 63.7 and Energy capacity per hour is greater than 19110 and
                                 effective mass is in near 21 Kgs. Reffering to the catalouges ew
                                 find AD-25-M (M for metric threading) suitable for the application
